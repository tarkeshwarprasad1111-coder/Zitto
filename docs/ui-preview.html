Zitto

Dragon Tiger played with virtual coins, with an analytics layer that is honest about what statistics can and cannot tell you. These are the screens as they exist in the codebase today.

Player app

Mobile-first, one-handed reach, dark throughout. Dragon reads red, Tiger reads blue, gold is reserved for the coin economy — so a colour never means two things at once.

Admin console

Desktop-first, deliberately plainer than the player app — this is a working surface, not a showroom. Destructive actions stay behind a mandatory reason field that lands in the audit log.

What is real and what is not

Every screen above is rendered from the components and design tokens in the repository — the colours, spacing and copy match apps/web and apps/admin as built.

The numbers are fixture data. The pages currently read from lib/mock-data.ts; switching a page onto the live API is a one-line change in its query function. The API, database schema and game engine are written but have not been run yet — Node and Postgres are not installed on this machine, which is the next thing to sort out.
